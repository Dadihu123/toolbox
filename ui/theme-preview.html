01

Token 对照

暗色是本轮之前 main.html 的原值；浅色是本轮提案。右两列是 WCAG 2.1 对比度，由页面用 JS 从下面两套 CSS 变量现场计算，没有硬编码。

  • ✓≥ 4.5:1，正文可用。
  • △3.0–4.5:1，仅可用于大字（≥24px，或 ≥18.66px 且粗体）与非文本（图标、状态点、2px 指示条）。
  • ✗< 4.5:1 却按正文使用 → 整格标红；< 3:1 一律不合格（含非文本）。
  • 对比 ① / ② 的口径：文本 token（--fg*）→ ① 与 --bg、② 与 --bg2；强调/状态 token → ① 白色 #fff 压在该色填充上、② 该色作为文字放在 --bg 上。每格同时给出暗、浅两套数值。
  • 表面与描边（--bg* / --line*）不做正文对比；--*-soft 是半透明叠加色，平面比值无意义，叠加后的实际组合在 02/03 两节的说明里单独标注。
  • 合计— 个对比度数值，全部由 getComputedStyle 读到的十六进制值算出（WCAG 2.1 相对亮度公式）。

02

面板 460×560

按 1:1 重现 panel.html。面板是独立的无边框透明窗口（decorations(false)），所以给它垫一层桌面壁纸来判定半透明：右上角切换「背景」。

暗色 · 当前面板 · 1:1 原尺寸
  • 14px 圆角 / 1px --line 描边 / 底 rgba(20,22,26,.97)，没有外部阴影（窗口矩形会把阴影切开，见 panel.html 里的注释）。
  • 搜索栏 13×15 内距，占位符 --fg-faint，右侧 Esc 键帽。
  • 行：8×9 内距 / 8px 圆角 / 30px 图标方块；选中行底 --bg3、标题转 --sel-title（原文写死 #fff）。面板里 hover 即选中（mouseenter 直接移动选中行），所以没有独立 hover 样式——第 4 行就是 hover 的结果。
  • 动作行右侧是 kbd 键帽；来源为 installed 的行显示「第三方」。
  • 底部栏 rgba(27,30,36,.6)；列表溢出时出现 8px 自定义滚动条（thumb #2c323c，写死的）。
浅色 · 提案面板 · 1:1 原尺寸
  • 底 rgba(248,249,251,.98)、底栏 rgba(236,239,244,.65)、描边 --line #d5dae2。仍然没有外部阴影，靠 1px 描边从壁纸上分离。
  • 选中行 --bg3 #e9ecf1 + 标题 --fg：原文的 #fff 在浅色下等于消失，--sel-title 这一层 token 省不掉。
  • 占位符 / 副标题 --fg-faint 用的是 #5f6877，不是提案里的 #6e7787——提案值在 --bg 上只有 4.1:1，调深后 5.2:1（详见 05）。
  • !图标方块底色来自工具清单（#4ea1ff / #3ecf8e / #e8b23a / #b084ff），上面的白字只有 1.9–2.8:1。这是既有行为，本轮没动；浅色要不要改成深色字或 --accent-dim 底，需要你定。
  • !半透明几乎看不出：.98 的 alpha 只让壁纸透 2%。如果想要磨砂感，得降 alpha 并加 backdrop-filter，两者都会改变现有视觉，本轮没做。
03

主窗口 1000×700

建模尺寸取 main.rs 的 inner_size(1000, 700)。并排时按 62% 缩放显示；切到「仅暗色 / 仅浅色」就是 100% 原尺寸。压缩用的是 transform: scale()，所以文字像素和真实窗口一致，只是整体缩小。

主窗口内容定位 内容区约 900px 高 > 窗口 700px，两边的预览都可以直接滚轮滚动（滚动条按主题着色）
暗色 · 当前1000×700 · 62%
  • 标题栏 40px --bg2：18px 描边 logo + Toolbox + 0.2.0 副标签。右侧三个按钮是按你的要求补的（真实 main.html 现在只有最小化 / 关闭，没有最大化）。
  • 侧栏 200px --bg2：34px 渐变品牌方块、4 项导航（当前项 = --bg3 底 + 2px accent 左条 + 计数 pill）、底部版本 + 便携模式徽标。
  • 页头 22px 标题 + 副标题 + 主按钮；主按钮是 accent 填充 + #0b111a 深墨字（白字在 accent 上只有 2.7:1，全站都不该用）。
  • 工具卡：--bg2 + 12px 圆角，版本 pill / 来源 pill / 权限 chip / 打开 按钮。真实卡片这一行是「功能 + 快捷键」chip（.action-chip + kbd），这里按你的要求改成展示权限，样式复用同一套。
  • 快捷键表：表头 --bg3；生效行 --ok，冲突行 --warn + --danger 说明文字。
  • 外观卡的分段控件在本轮的语义是「这个开关终于能用了」，暗色下激活项用 --accent 文字（6.8:1，没问题）；权限审查卡的复选框用 accent。
浅色 · 提案1000×700 · 62%
  • 表面：#f4f5f7 底 + #fff 卡片，只靠 1px --line-soft 分隔（浅色下不要靠阴影分层，卡片阴影只在 hover 时出现）。内容区顶部仍有 accent 冷光晕（rgba(43,108,176,.06)）。
  • 导航激活项 --bg3 + --fg（13.9:1）——这个「底色 + 强文字 + accent 装饰条」的组合在浅色下最稳。
  • 主按钮照旧 accent 填充 + #0b111a（7.1:1）；没有为了浅色改成白字。
  • 状态色：--ok 只放在 --bg2 卡片上（4.7:1）；直接放 --bg 上是 4.3:1，不够——所以「已启用」这类文字请留在卡片里。
  • !激活分段项的平面值只有 4.5:1，而它的底色是 --accent-soft 叠加，实际掉到 ≈4.0:1；来源 pill「官方」同理 ≈4.3:1。这是「soft 底 + 彩色字」这个模式在浅色下的通病，见 05 的待定项。
  • !工具图标白字同左栏，浅色下没变化（底色来自工具清单）。

05

变更摘要

本轮只提出 token 与替换点，不动实现。所有比值都是页面上现算出来的。

浅色新增

  • --accent-text #1f6fd0：新 token，专门给「浅色下的彩色文字」。暗色里它只是 --accent 的别名（#4ea1ff），不引入新颜色。
  • --ok/--warn/--danger 换成同色相的深色版：#17845a / #94620a / #c62f35（暗色那三支放到白底上是 1.9–3.9:1，直接搬会瞎）。
  • 四个 --*-soft 换成同色低透明版本；浅色下 alpha 略降（accent .12→.10，danger .11→.10）。
  • 浅色的 --bg2 是纯白、--bg 是冷灰 #f4f5f7：卡片靠「白 + 1px 线」立起来，不靠阴影。

保持不动

  • --accent #4ea1ff 两套完全相同：色相不动，强调色在浅色里继续负责「填充、图标、2px 指示条」。
  • --accent-dim #2b6cb0 两套相同（渐变终点、图标方块底）。
  • --mono 字体栈两套相同。
  • 悬浮球与悬停快捷扇的绘制参数：见 04，本轮不改。

调整（唯一一处，必须报告）

  • 浅色 --fg-faint：提案 #6e7787 → 采用 #5f6877。
  • 原因：提案值在 --bg 上是 4.1:1、--bg2 上是 4.5:1、--bg3 上只有 3.8:1——而它就是占位符、副标题、版本号、表头文字的颜色，按正文用。
  • 调整后：--bg 5.2:1、--bg2 5.6:1、--bg3 4.8:1，三处都过 4.5。
  • --fg / --fg-dim 没有动：--fg 15.2:1、--fg-dim 7.1:1 本来就够。

两条你点名的说明

  • (a) 要不要加 --accent-text：要。--accent 在浅色 --bg 上只有 2.4:1、白卡上 2.7:1，而 main.html 里 a / .link-btn / .seg-item.active / .hk-status 的激活文字都用 --accent，浅色必须换成 --accent-text（对 --bg 4.5:1、对白卡 5.0:1）。
  • (b) 命名不一致：确认。panel.html 用 --bg-2 / --bg-3，main.html 用 --bg2 / --bg3。本预览统一用 --bg2 / --bg3（与 main.html 一致、改动面更小）；S1 应把 panel.html 的两处别名删掉，别在主题层留两种拼法。

写死颜色：做浅色时必须提取

  • #fff（panel 选中行标题）→ --sel-title，浅色 #1b1f27。
  • #2c323c / #303540（两个滚动条，现在就各写各的）→ 统一 --scroll-thumb，浅色 #c4cbd6。
  • #0b111a（主按钮文字）→ --primary-ink；#65aeff（主按钮 hover）→ --accent-hover。
  • rgba(78,161,255,.28) 等四个 soft 描边 → --accent-line / --ok-line / --warn-line / --danger-line（浅色要另一组 alpha，否则边框会脏）。
  • rgba(255,255,255,.018)（表格 hover 洗色）→ --hover-wash，浅色 rgba(27,31,39,.025)；rgba(78,161,255,.07)（内容区光晕）→ --content-glow。

风险 / 需要你拍板

  • 「soft 底 + 彩色字」在浅色下集体掉到 4.0–4.3:1：分段控件激活项 ≈4.0、来源 pill ≈4.3、badge-ok ≈4.0。要么把 --accent-text 再压深（#1a5fae 在 accent-soft 上 ≈5.1:1），要么浅色下激活态改成「--bg3 底 + --fg 字 + accent 装饰条」。二选一，本轮没替你定。
  • 工具图标白字：#4ea1ff 2.7:1 / #3ecf8e 2.0:1 / #e8b23a 1.9:1。底色来自工具清单而不是主题，浅色下是否改用深色字 / 统一 --accent-dim 底，需要你定。
  • 半透明面板：.98 的 alpha 在浅色壁纸上几乎看不出透明，又没有 backdrop-filter。要么接受「接近不透明」，要么单独做一版磨砂（会改视觉，建议另开一轮）。
  • 暗色侧既有问题（本轮不改，仅记录）：--fg-faint 在 --bg 上 3.8:1、--bg2 上 3.5:1，本来就低于 4.5；#fff 压 --accent 只有 2.7:1（品牌方块图标、球内图标、任何 accent 上的白字）。要不要顺手一起修，你定。
  • 页面外观不属于提案：工具栏、表格、说明文字用的是中性评审配色（--s-*），只有 02/03 两张 mock 内部读的是提案 token。
