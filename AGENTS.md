## Agent skills

### Issue tracker

Issues and specs for this repo live in GitHub Issues (`Dadihu123/toolbox`), driven by the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each label string equal to its role name: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

single-context — one root `GLOSSARY.md` plus `docs/adr/` for architecture decisions. See `docs/agents/domain.md`.
